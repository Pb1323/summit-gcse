# Summit GCSE

Exam-board-specific GCSE study notes. Starting subject: **OCR GCSE Economics
(J205)** — all 4 topics, 23 subtopics, with key terms and exam tips.

## Stack

Next.js (App Router) + TypeScript + Tailwind CSS v4. Fully static — no
database, no auth, no payments.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

On Windows PowerShell, use `npm.cmd run dev` if `npm.ps1` is blocked.
